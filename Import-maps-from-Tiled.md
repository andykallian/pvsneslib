This tutorial will help you to understand how to use the PVSnesLib map engine. The source code is available in examples part of pvsneslib.

## Install Tiled

Go to https://www.mapeditor.org/ and download Tiled for your operating system (download is available at https://thorbjorn.itch.io/tiled).  

Warning ! You must use a V1.9.x to be compatible with tmx2snes tool.

## Create a tmx compatible file from a bitmap

Go to https://portabledev.com/pvsneslib/tilesetextractor/ and upload your png file to allow the tool to create tileset and tmx files.
