## Install Tiled

Go to https://www.mapeditor.org/ and download Tiled for your operatring system.  

Warning ! You must use a V1.9.x to be compatible with tmx2snes tool.

## Create a tmx compatible file from a bitmap
Go to https://portabledev.com/pvsneslib/tilesetextractor/ and download your png file to allow the tool to create tileset and tmx files.
